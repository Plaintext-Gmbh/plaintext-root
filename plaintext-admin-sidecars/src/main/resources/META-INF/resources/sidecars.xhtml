Sidecars

Sidecars sind eigenständige Container, die dieser Anwendung Dienste anbieten. Jeder beschreibt sich über das Plaintext-Sidecar-Protokoll mit Status, Version und Fähigkeiten. Tokens und Passwörter werden verschlüsselt gespeichert und nie angezeigt.

#{sidecarsBean.anzahlOk} ok #{sidecarsBean.anzahlEingeschraenkt} eingeschränkt #{sidecarsBean.anzahlFehler} Fehler #{sidecarsBean.anzahlTokenFehlt} ohne gültigen Token
#{z.sidecar.name} #{z.sidecar.titel} #{z.sidecar.version} #{z.faehigkeiten.size()} #{z.sidecar.quelle == 'KONFIG' ? 'Konfiguration' : 'von Hand'}
#{z.sidecar.url} · #{z.sidecar.quelle == 'KONFIG' ? 'aus plaintext.sidecars' : 'von Hand ergänzt'}
Teile
#{t.name()}: #{t.text()}
Fähigkeiten
#{f.id()} #{f.titel()} #{f.methode()} #{f.pfad()} #{f.seiteneffekt()}#{f.perMcpAufrufbar() ? ' · MCP' : ''}
Zugang: #{sidecarsBean.authText(z.sidecar.authZustand)}
Doku

Eine Ablage ist ein Ordner auf einem Speicher (heute Nextcloud), in dem Module Dateien ablegen, z. B. Draw.io seine Diagramme. Erlaubt sind öffentliche Adressen und die in plaintext.ausgehend.erlaubte-hosts freigegebenen.

#{sidecarsBean.anzahlAblagenOk} ok #{sidecarsBean.anzahlAblagenFehler} Fehler
#{a.name} Nextcloud #{a.url} #{a.benutzer} #{a.pfad} #{sidecarsBean.zeit(a.letztePruefung)}
App-Passwort #{a.hatPasswort() ? 'hinterlegt (verschlüsselt)' : 'fehlt'}
 Der Name kommt aus der Beschreibung des Sidecars. Erlaubt sind die Hosts aus plaintext.sidecars und plaintext.sidecars.erlaubte-hosts.
