Styleguide

Die fünf Regeln

Entscheid vom 15.10.2026 — gilt für jede neue Seite, hell und dunkel.

  1. Ein Seitenkopf: Titel links, eine Hauptaktion rechts, Zeilenaktionen in der Zeile, Seltenes im «⋯»-Menü (pt:seitenkopf).
  2. Tabellen: ein Paginator unten erst ab Seite 2, ein deutscher Leerzustand mit Weg, Zahlen rechtsbündig mit gleich breiten Ziffern (pt:tabelle, pt:colAmount).
  3. Eine Sprache, ein Meldungsort: Meldungen über FacesMessages an das eine Growl, Rückfragen über den einen ConfirmDialog — beide liefert das Template.
  4. Tokens statt Inline-Farben: Fläche, Text, Akzent, Status; vier Abstände, ein Radius, eine Schrift in drei Größen. Status als leiser Chip, keine Emoji in Titeln.
  5. Mobil als eigener Entwurf: eine sichtbare Aktion, Tabellen als Karten mit 2–3 Feldern, Filter hinter einem Knopf.

Farbrollen

Vier Rollen. Der Akzent ist die gewählte Farbvariante (Grün, Blau oder Orange); alles andere folgt hell und dunkel von selbst.

Abstand, Radius, Schrift

Vier Abstände, ein Radius, eine Schriftfamilie in drei Größen — mehr gibt es nicht.

Status

Ein Status ist ein leiser Chip (pt:chip), nie farbiger Text.

Tabelle mit mehreren Seiten

Paginator unten, weil es mehr als eine Seite gibt. Auf dem Telefon: jede Zeile eine Karte mit Nummer, Kunde und Status; die Filter hinter dem Knopf.

Tabelle mit einer Seite

Drei Zeilen passen auf eine Seite — also kein Paginator.
